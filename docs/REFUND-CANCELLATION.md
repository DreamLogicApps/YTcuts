# Refund and Cancellation Policy

**Last updated: 2026-09-30**

YT Cuts currently has no paid plans, checkout, subscription, license fee, or payment processor. There are therefore no purchases or refunds to process in this version.

A user can request cancellation of an active local download using **Stop Download**. Cancellation attempts to terminate the local `yt-dlp` process and remove that task's temporary files. A process may take a short time to stop, and a completed file is not automatically deleted by cancellation.

If a future release introduces paid functionality, this document must be replaced with product-specific pricing, renewal, cancellation, refund timing, statutory consumer rights, support contact details, and payment-provider terms before payment is enabled. It should be reviewed by qualified legal counsel for each target market.
